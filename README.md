# Douyin Identity Cover

用一张本人照片建立稳定的人物身份，再根据不同选题生成自然的多角度、多动作、多服装抖音封面。

这个 Skill 保留的是“同一个人”，不是“同一张正脸”：身体动作变化时，会同步重建头部转向、视线、下颌、脖子、肩膀和手势，避免贴脸感与扭脖子。

## 能力

- 单张身份照驱动多角度人物封面
- 根据选题变化动作、服装、表情与构图
- 加入产品 UI、设备、结果卡等交付证据
- 固定输出 1080×1920 抖音母版
- 同步生成 1080×1440 居中裁切预览
- 对头颈关系、手部、身份漂移、中文标题和安全区进行验收

## 安装

把仓库克隆到 Codex Skills 目录：

```bash
git clone https://github.com/BorisSun0424-boop/douyin-identity-cover.git ~/.codex/skills/douyin-identity-cover
```

重新启动 Codex 后，可以自然语言调用，也可以显式指定：

```text
使用 $douyin-identity-cover，根据这张本人照片制作抖音封面。
标题：如何给自己的智能体自定义配置模型
背景证据：这张 WorkBuddy 配置截图
```

## 输入与输出

输入至少包含一张清晰本人照片和准确标题。产品截图、设备照片或结果图不是必需项，但能让封面更直观地表达视频交付内容。

输出包括：

- `*-9x16.png`：1080×1920 母版
- `*-3x4-preview.png`：1080×1440 安全裁切预览

人物照片仅在本地任务中作为身份参考，不应提交到此 Skill 仓库。
